# Papra

Papra is a minimalist, open-source document management and archiving tool designed for self-hosting.

## Features

- **Document Management** — Upload, organize, and archive your documents with a clean modern interface.
- **OCR & Text Extraction** — Automatically extract text from uploaded documents for full-text search.
- **Document Deduplication** — Detect and prevent duplicate documents.
- **Tagging & Tagging Rules** — Organize documents with tags and automate tagging with rules.
- **Advanced Search** — Full-text search powered by SQLite FTS5.
- **Organizations** — Multi-tenant support with organizations and role-based access.
- **Ingestion Folders** — Watch folders for new documents and automatically import them.
- **Intake Emails** — Receive documents via email.
- **Document Encryption** — Optionally encrypt documents at rest.
- **No-Mutation Principle** — Original documents are never modified.
